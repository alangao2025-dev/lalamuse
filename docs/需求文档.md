# Muse & Bloom 女性时尚独立站 — 需求文档 v0.2

> 项目名 lalamuse，原型预览：https://lalamuse.accrepo.com （后台 /admin）。品牌名、配色都是暂定，可以改。
>
> v0.2 变更：前台支持英文 / 中文切换（默认英文）；后台商品、内容、首页文案增加中文字段。

## 1. 项目定位

| 项 | 内容 |
|---|---|
| 业务 | 跨境 B2C 外贸独立站：女装、鞋履、包袋、饰品、配饰 |
| 差异点 | “内容 + 电商”：用穿搭图文、短视频种草，内容页直接挂商品，一键购买整套搭配 |
| 目标用户 | 欧美 / 东南亚 22–40 岁女性，移动端为主（预计 70%+ 流量来自手机） |
| 语言 / 币种 | 首期英文（默认）+ 中文，美元结算；二期增加西 / 法 / 德等语言和多币种自动换算 |
| 视觉 | 柔和、高级、留白多：奶油白 + 裸粉 + 玫瑰灰 + 香槟金；衬线标题 + 无衬线正文 |

## 2. 角色

1. **访客**：浏览商城、穿搭知识，加购物车，可游客下单。
2. **注册会员**：收藏、订单查询、地址簿、积分 / 优惠券（二期）。
3. **运营管理员**：上架商品、发布图文 / 视频、处理订单、看数据。
4. **超级管理员**：在运营权限之上，管理员工账号、支付 / 物流 / 站点设置。

## 3. 前台（对外网站）功能

### 3.1 首页
- 顶部公告条（如 “Free shipping over $79”），可在后台改。
- 首屏大图轮播 / 主推活动，按钮跳到分类或专题。
- 分类入口：Clothing / Shoes / Bags / Jewelry / Accessories。
- 新品、热卖商品区。
- “Shop the Look” 穿搭专题：一张搭配图 + 组成单品，可整套加购。
- 穿搭知识精选（图文 + 视频）。
- 邮件订阅（送首单折扣码），社交媒体链接（Instagram / TikTok / Pinterest）。

### 3.2 商城
- 分类列表页：按分类、价格区间、颜色、尺码筛选；按新品 / 价格 / 销量排序。
- 搜索：商品名、标签。
- 商品详情：多图、颜色 / 尺码选择、库存提示、尺码表、材质与护理、配送与退换说明、“搭配推荐”、相关穿搭文章、评价（二期）。
- 收藏（心形按钮）。

### 3.3 购物车与结账
- 侧滑购物车：改数量、删除、显示免运费差额。
- 结账（单页）：联系邮箱 → 收货地址 → 配送方式（标准 / 加急）→ 优惠码 → 支付。
- 支付方式：信用卡（Stripe）、PayPal、Apple Pay / Google Pay（通过 Stripe）。**原型里只模拟支付成功**。
- 下单成功页 + 订单确认邮件（正式版）。
- 游客下单，可在成功页一键注册。

### 3.4 穿搭知识（Style Journal）
- 内容类型：图文文章、视频（竖屏短视频 / 横屏长视频）。
- 栏目：Styling Tips / Trend Report / Capsule Wardrobe / Occasion Wear / Care Guide。
- 文章详情：封面、正文（图文混排）、文中关联商品卡片（可直接加购）、相关文章。
- 视频：封面 + 播放，旁边挂关联商品。

### 3.5 会员中心
- 登录 / 注册（邮箱 + 密码，二期加 Google / Apple 登录）。
- 我的订单（状态：待支付 / 已支付 / 已发货 / 已完成 / 已退款）、物流单号。
- 收藏夹、地址簿。

### 3.6 多语言（英文 / 中文）
- 默认语言：英文。首次访问一律显示英文。
- 切换入口：页面顶部导航栏右侧固定显示 “🌐 EN | 中文” 切换按钮，当前语言高亮；手机端同样显示在顶栏，侧滑菜单顶部也有一份。
- 切换后立即生效，不刷新页面、不丢失购物车；选择保存在浏览器中，下次访问保持上次的语言。
- 切换范围：前台全部界面文字（导航、按钮、提示、结账、会员中心、页脚、Cookie 提示等），以及商品名称 / 描述 / 材质、文章 / 视频的标题 / 摘要 / 正文、首页公告和横幅文案、分类和栏目名称、颜色名称。
- 内容兜底：某条商品或文章没有填写中文时，自动显示英文，不出现空白。
- 不随语言变化：价格币种（USD）、尺码、品牌名、订单号。
- 中文模式使用中文字体（思源宋体 / 思源黑体），页面 `lang` 属性随语言切换（利于 SEO 和读屏）。
- 正式版：中英文使用不同网址（如 `/zh/...`），各自生成 sitemap 并标注 hreflang，方便搜索引擎分别收录；按浏览器语言给出切换建议，但不自动跳转。

### 3.7 通用
- 手机、平板、电脑自适应；手机端底部导航、侧滑菜单。
- 页脚：关于我们、配送政策、退换政策、隐私政策、联系客服。
- SEO：每个商品 / 文章可设置标题、描述、URL 别名；生成 sitemap。
- Cookie 同意提示（欧盟 GDPR）。

## 4. 管理后台功能（中文界面）

### 4.1 登录与权限
- 账号密码登录；两种角色：运营、超级管理员（见第 2 节）。

### 4.2 数据概览
- 今日 / 本月销售额、订单数、客单价、新增会员。
- 近 7 天销售趋势、热销商品排行、待处理订单数。

### 4.3 商品管理
- 列表：搜索、按分类 / 状态筛选、批量上下架。
- 新增 / 编辑：名称、分类、价格、划线价、库存、颜色、尺码、多图上传、描述、标签、是否新品 / 热卖、SEO 信息。
- 中文版本：中文名称、中文描述、中文材质与护理（选填，留空则前台中文模式显示英文）；列表中同时显示中英文名称。
- 状态：草稿 / 已上架 / 已下架。

### 4.4 内容管理（宣传资料）
- 图文文章：标题、栏目、封面、摘要、正文、关联商品、发布状态。
- 中文版本：图文和视频都可填写中文标题、中文摘要、中文正文（选填）。
- 视频：标题、封面、视频文件或链接（YouTube / TikTok 外链或自传）、关联商品。
- 首页配置：轮播图、公告条、Shop the Look 专题；公告条、首屏标题 / 副标题、搭配专题标题均有英文和中文两份。

### 4.5 订单管理
- 列表：按状态 / 日期 / 订单号搜索。
- 详情：商品、金额、收货地址、支付信息。
- 操作：标记发货（填物流公司 + 单号）、完成、退款。

### 4.6 客户管理
- 会员列表、累计消费、订单数、订阅状态。

### 4.7 设置
- 店铺信息、免运费门槛、运费、支付方式开关、优惠码。

## 5. 非功能要求
- 手机端首屏加载 < 3 秒；图片自动压缩、懒加载。
- 支付走 Stripe / PayPal 托管页面，网站不保存银行卡信息（PCI 合规）。
- HTTPS、后台登录限流、操作日志。

## 6. 正式版技术方案（建议）
- 前台 + 后台：React，部署在 Cloudflare（全球 CDN，海外访问快）。
- 接口：Cloudflare Workers + Hono；数据库：Cloudflare D1。
- 图片 / 视频：Cloudflare R2 存储（需开通，绑定付款方式）；视频也可用 YouTube / TikTok 外链。
- 支付：Stripe（信用卡、Apple Pay、Google Pay）+ PayPal。
- 邮件：Resend 或 SendGrid（订单通知、订阅）。

## 7. 原型范围（本次交付）
- 前台：首页、商城列表、商品详情、购物车、结账（模拟支付）、穿搭知识列表 / 详情 / 视频、会员中心（订单、收藏）。
- 语言：前台默认英文，顶部 “EN | 中文” 切换；示例商品、文章和首页文案已配好中文。
- 后台 `/admin`（中文界面，不切换语言）：登录、数据概览、商品管理（含图片上传、中文字段）、内容管理（图文 / 视频、中文字段）、订单管理（改状态 / 发货）、客户、设置（含首页中文文案）。
- 数据保存在浏览器本地（localStorage），后台改动即时反映到前台；可在后台“设置”里一键恢复示例数据。
- 商品图用插画占位，正式上线换成实拍图。
- 原型的中英文共用同一网址（语言存在浏览器里）；按语言区分网址留到正式版。

## 8. 待确认
1. 品牌名、Logo、域名。
2. 首期面向哪些国家（影响语言、币种、物流和税）。
3. 支付渠道：Stripe + PayPal 是否可行（需要海外主体或支持中国大陆主体的方案）。
4. 物流：自发货还是 3PL / 海外仓；运费按重量还是固定价格。
5. 中文版面向哪些用户（海外华人 / 国内用户）——影响是否需要人民币显示、支付宝 / 微信支付；其他语言和多币种是否首期上线。
6. 退换货政策（天数、谁承担运费）。
7. 中文内容由谁翻译维护（人工 / 机器翻译后人工校对）；后台是否需要“一键机器翻译”按钮。
